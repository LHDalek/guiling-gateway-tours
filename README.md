# Guilin Gateway Tours

A professional English-language travel website for Guilin, China — showcasing tour packages for international tourists.

## 🌐 Live Website

**URL:** [https://guilin-gateway.vercel.app](https://guilin-gateway.vercel.app)

## ✨ Features

- **Hero Section** — Stunning Guilin landscape with call-to-action
- **Tour Packages** — 3 curated experiences (Li River Cruise, Yangshuo Discovery, Food Tour)
- **Responsive Design** — Works on desktop, tablet, and mobile
- **Contact Form** — Inquiry form for booking requests
- **Customer Reviews** — Testimonials from international travelers

## 🛠 Tech Stack

- HTML5
- CSS3 (Custom properties, Flexbox, Grid)
- Vanilla JavaScript
- Google Fonts (Playfair Display + Inter)

## 🚀 Deployment

This site is automatically deployed to Vercel on every push to the main branch.
